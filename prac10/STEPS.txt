Aim: send live air quality readings through Kafka, store them in ClickHouse, and show them on a Grafana dashboard that updates by itself.

IN SIMPLE WORDS
---------------

This practical joins five small parts into one pipeline. Data moves from left to right:
   1. Producer (Python): makes a fake air quality reading for a random city every 2 seconds and sends it to Kafka.
   2. Kafka: carries the messages in a topic called air_quality.
   3. Consumer (Python): reads each message from Kafka and inserts it as a row into ClickHouse.
   4. ClickHouse: an OLAP database. OLAP means it is built for fast analysis (average, count, group by) over huge numbers of rows. It stores data column by column, which makes such queries fast.
   5. Grafana: a dashboard tool. It runs a SQL query on ClickHouse every few seconds and draws the graph.

Kafka is the conveyor belt, ClickHouse is the warehouse, Grafana is the TV screen showing what is in the warehouse.

If something goes wrong
   - failed to read dockerfile: the file is not named exactly Dockerfile, or it is not inside prac10.
   - The producer or consumer keeps restarting for more than 2 minutes: run docker compose logs consumer and read the last error line.
   - Table default.air_quality does not exist in step 8: the consumer has not started yet. Wait for the first Inserted: line.
   - Save & test fails in Grafana: check the server address is clickhouse, the port is 9000 and the protocol is Native. For port 8123 the protocol must be HTTP.
   - The graph says "No data": set the time range to Last 15 minutes, and check the query still contains $__timeFilter(event_time).

CODE 1 (DOCKER-COMPOSE.YML)
---------------------------

Your journal's file with one addition: restart: on-failure on the producer and consumer. If Kafka is not ready yet, the Python program stops and Docker starts it again automatically. This lets the Python files be much shorter.

      services:
        kafka:
          image: apache/kafka:3.9.1
          ports:
            - "9092:9092"
          environment:
            KAFKA_NODE_ID: 1
            KAFKA_PROCESS_ROLES: broker,controller
            KAFKA_LISTENERS: PLAINTEXT://:9092,CONTROLLER://:9093
            KAFKA_ADVERTISED_LISTENERS: PLAINTEXT://kafka:9092
            KAFKA_CONTROLLER_LISTENER_NAMES: CONTROLLER
            KAFKA_CONTROLLER_QUORUM_VOTERS: 1@kafka:9093
            KAFKA_LISTENER_SECURITY_PROTOCOL_MAP: CONTROLLER:PLAINTEXT,PLAINTEXT:PLAINTEXT
            KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR: 1
            KAFKA_TRANSACTION_STATE_LOG_REPLICATION_FACTOR: 1
            KAFKA_TRANSACTION_STATE_LOG_MIN_ISR: 1
            KAFKA_GROUP_INITIAL_REBALANCE_DELAY_MS: 0
            KAFKA_NUM_PARTITIONS: 1
      
        clickhouse:
          image: clickhouse/clickhouse-server:latest
          ports:
            - "8123:8123"
            - "9000:9000"
          environment:
            CLICKHOUSE_SKIP_USER_SETUP: 1      # allows login as "default" with no password
      
        grafana:
          image: grafana/grafana:latest
          ports:
            - "3000:3000"
          environment:
            GF_INSTALL_PLUGINS: grafana-clickhouse-datasource
          depends_on:
            - clickhouse
      
        producer:
          build: .
          command: python -u producer.py
          restart: on-failure
          depends_on:
            - kafka
      
        consumer:
          build: .
          command: python -u consumer.py
          restart: on-failure
          depends_on:
            - kafka
            - clickhouse

CODE 4 (PRODUCER.PY), THE EASY VERSION
--------------------------------------

      import json, random, time
      from datetime import datetime, timezone
      from kafka import KafkaProducer
      
      producer = KafkaProducer(
          bootstrap_servers="kafka:9092",
          value_serializer=lambda v: json.dumps(v).encode("utf-8"))
      
      cities = ["Mumbai", "Pune", "Nashik", "Nagpur"]
      print("Air Quality Producer Started", flush=True)
      
      while True:
          reading = {
              "event_time": datetime.now(timezone.utc).strftime("%Y-%m-%d %H:%M:%S"),
              "city": random.choice(cities),
              "pm25": round(random.uniform(10, 180), 2),
              "pm10": round(random.uniform(20, 250), 2),
              "temperature": round(random.uniform(24, 38), 2),
          }
          producer.send("air_quality", value=reading)   # send to Kafka
          print("Sent:", reading, flush=True)
          time.sleep(2)                                 # one reading every 2 seconds

CODE 5 (CONSUMER.PY), THE EASY VERSION
--------------------------------------

      import json
      from datetime import datetime, timezone
      import clickhouse_connect
      from kafka import KafkaConsumer
      
      # 1. Connect to ClickHouse and create the table if it is not there
      client = clickhouse_connect.get_client(
          host="clickhouse", port=8123, username="default", password="")
      client.command("""
          CREATE TABLE IF NOT EXISTS default.air_quality (
              event_time DateTime,
              city String,
              pm25 Float64,
              pm10 Float64,
              temperature Float64
          ) ENGINE = MergeTree ORDER BY (city, event_time)
      """)
      
      # 2. Connect to the Kafka topic
      consumer = KafkaConsumer(
          "air_quality",
          bootstrap_servers="kafka:9092",
          auto_offset_reset="earliest",
          group_id="air-quality-group",
          value_deserializer=lambda v: json.loads(v.decode("utf-8")))
      print("Kafka Consumer Started", flush=True)
      
      # 3. Every message becomes one row in ClickHouse
      for message in consumer:
          r = message.value
          # ClickHouse needs a real datetime, not text
          t = datetime.strptime(r["event_time"], "%Y-%m-%d %H:%M:%S").replace(tzinfo=timezone.utc)
          client.insert(
              "default.air_quality",
              [[t, r["city"], r["pm25"], r["pm10"], r["temperature"]]],
              column_names=["event_time", "city", "pm25", "pm10", "temperature"])
          print("Inserted:", r, flush=True)

Your journal's two Python files do the same work but wrap every connection in a while True: try ... except ... sleep(3) loop to wait for Kafka and ClickHouse. Here Docker's restart: on-failure does that waiting, so you may see one or two "exited with code 1" lines at the start. That is expected.

CODE 6: THE GRAFANA QUERY
-------------------------

      SELECT
          toStartOfMinute(event_time) AS time,
          city,
          avg(pm25) AS pm25
      FROM default.air_quality
      WHERE $__timeFilter(event_time)
      GROUP BY time, city
      ORDER BY time

It gives the average PM2.5 per city per minute. $__timeFilter is a Grafana shortcut that keeps only rows inside the time range chosen at the top right. Set the query type to Time series to get one line per city.
